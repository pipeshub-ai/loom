# Roadmap

## v0.12 (Next)
- Streaming agent responses
- Jupyter notebook integration
- Improved error messages with diagnostics

## v1.0 (Stable)
- Stable public API (no breaking changes after 1.0)
- PostgresStore battle-tested in production
- Temporal backend (`DurabilityBackend` implementation)
- Comprehensive API documentation

## v1.1
- VS Code extension for workflow development
- MCP server for Claude Desktop / Cursor integration
- Webhook listener (built-in HTTP server)

## v2.0
- Distributed scheduler with Redis-backed trigger claiming
- Multi-tenant support (org-level isolation)
- High availability (leader election, worker fleet)
- RBAC (role-based access control)
