Build a multi-channel publisher.

It should:
1. Generate several genuinely different variants about a topic using AI
2. Drop duplicates within the batch, and also anything this workflow has
   already published in an earlier run
3. Score the remaining variants and pick the best, keeping the reason
4. Ask a person before anything is posted
5. Publish the winner to every configured channel in parallel, bounded, and
   report which landed
6. Remember only what actually posted, so a failed publish can be retried later

Return counts of variants generated, suppressed as already-said, and duplicated
within the batch, plus the per-channel results.
